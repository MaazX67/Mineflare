# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-25

### Added
- Initial framework release
- Core systems: Logger, EventBus, ConfigLoader, BotManager
- Bot systems: BotInstance, StateManager, RecoveryManager
- Task system with priority queue
- Command system with registry and parser
- Behavior engine for autonomous decision-making
- Memory management with persistent knowledge base
- Inventory management system
- Navigation system with movement and obstacle avoidance
- Combat systems: PvE and PvP controllers
- Building system with schematic support
- Plugin system for extensibility
- REST API server
- Real-time dashboard with Socket.IO
- Configuration management
- Comprehensive utilities and validators
- Built-in commands: help, status, echo
- Structured logging with Pino
- Documentation and examples

### Features
- Event-driven architecture
- Priority-based task queue
- Autonomous behavior system
- Extensible command framework
- Persistent and runtime memory
- Real-time web dashboard
- REST API endpoints
- Plugin loading system
- Comprehensive logging
- Error recovery and reconnection
